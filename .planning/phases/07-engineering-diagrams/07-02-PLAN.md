<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo file content (at release tag) → published markdown page | Diagram source file CONTENT is read via `FileFetcher` and wrapped verbatim into a published page. Maintainer-committed (same trust as any repo file), but flows into a published artifact. |
| config source path → derived `Artifact.Filename` | A config-supplied source path is reduced to a published sub-path; must not escape `releases/<tag>/`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03 | Tampering | `diagramName(srcPath)` → `Artifact.Filename` | mitigate | Derive the filename segment via `path.Base` ONLY (render.go task 1), stripping all directory components, so the emitted `Filename` ("diagrams/<type>/<base>.md") cannot contain `../`. Never pass the raw config path into `Filename` (RESEARCH Pitfall 4). The pages publisher additionally prefix-guards under `{dir}/` (plan 03 test asserts this). |
| T-07-04 | Tampering | `wrapMermaidFence` over attacker-influenceable source content (markdown/fence breakout) | accept | The source is maintainer-committed at the same trust level as any repo file; a source containing a literal ` ``` ` line would corrupt only its own page render and cannot escape the artifact boundary (RESEARCH Security Domain). Documented as accepted for v1; optional fence-terminator skip is a non-blocking hardening. The first-line keyword sniff already rejects non-Mermaid (`.puml`/`.dot`/prose) → skip (D-02/D-08). |
| T-07-05 | Spoofing | non-Mermaid content published as a "diagram" | mitigate | `sniffMermaid` (task 1) rejects any source whose first significant line is not a recognized Mermaid keyword for the type → `slog.Warn` + skip (DIAG-04 / D-02). |
| T-07-06 | Denial of Service | oversized diagram source file | accept | Single-file fetch from the repo; existing `FileFetcher`/adapter fetch limits apply. No recursive `$ref` resolution (unlike apidocs). Low risk (RESEARCH Security Domain). |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | This plan installs NO packages — stdlib (`bytes`, `strings`, `path`, `log/slog`, `context`, `testing`, `os`) + existing internal packages only (RESEARCH Package Legitimacy Audit: "not applicable"). No legitimacy gate needed. |
</threat_model>
