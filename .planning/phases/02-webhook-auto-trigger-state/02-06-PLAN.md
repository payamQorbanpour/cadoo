<objective>
Make `cadoo-worker` consume `release_docs` jobs: construct a `releasedocs.Dispatcher` (with blog generator + pages publisher in the default slices, and the DB-backed `state.Store` when `DATABASE_URL` is set) and register it through the extended `riverq.New` from 02-05. Add a nil-tolerant `PostedStore` hook to the dispatcher so successful publishes are recorded for cross-restart idempotency.

Purpose: closes the dual-mode loop — 02-05 enqueues, this plan consumes. REQ-release-docs-idempotency (DB-backed), and completes the wiring of blog (REQ-release-artifact-generation) and pages (REQ-publish-destinations) into the running worker.

Output: extended default generator/publisher slices; a `PostedStore` interface field on `releasedocs.Dispatcher` (satisfied by `*state.Store`) that records publish state after each run (nil → no-op, stateless marker mode); worker `buildReleaseDispatcher`/`runRiver` wiring that builds the releasedocs dispatcher and passes it to `riverq.New`.
</objective>
