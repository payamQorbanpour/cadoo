<objective>
Establish the Phase-1 contract layer for the Release Docs subsystem: the new `vcs` capability
interfaces and normalized types, the `releasedocs` core types/interfaces (`Generator`, `Publisher`,
`Registry`, `ReleaseJob`, `ReleaseContext`, `SemverBump`, `ArtifactKind`, `PublishTarget`,
`Artifact`, and a releasedocs-local `FileFetcher`), the locked idempotency marker constants + splice
helpers, the `config.ReleaseDocs` schema, and a shared, importable fake `vcs.Provider` test helper in
its own `releasedocstest` package. Every later plan in this phase implements against these contracts —
they receive the contracts here, not by exploring the codebase.

Purpose: Interface-first ordering. Downstream plans (context builder, template, adapters,
generators, publishers, dispatcher/CLI) all consume these types. Defining them once, correctly,
prevents the scavenger-hunt anti-pattern and lets Wave 2 run in parallel.

Output: `internal/releasedocs/releasedocs.go`, `internal/releasedocs/marker.go`,
`internal/releasedocs/releasedocstest/fake.go`, additions to `internal/vcs/vcs.go` and
`internal/config/config.go`, and `golang.org/x/mod/semver` added to `go.mod`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.cadoo.yaml` (tag tree) → config parser | Operator-authored config crosses into typed structs; could carry unexpected/large values |
| VCS API → normalized vcs types | Provider response data (commit messages, PR titles/bodies) becomes typed input later flowing into generated markdown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | config.ReleaseDocs parsing | accept | yaml.v3 via existing `config.Parse`; unknown keys ignored; no eval of config values. Low risk — operator-authored, same trust as existing `.cadoo.yaml`. |
| T-01-02 | Information disclosure | new vcs capability interfaces | mitigate | Interfaces carry no token fields; tokens stay inside adapter `*Adapter` (never logged), consistent with existing adapters. No secret added to ReleaseContext. |
| T-01-03 | Tampering | marker constants | mitigate | Marker strings locked as exported constants in marker.go from day one (Runtime State Inventory); changing them later is a documented breaking change, preventing accidental drift across publishers. |
| T-01-SC | Tampering | `go get golang.org/x/mod` | mitigate | Task 0 blocking-human checkpoint verifies official module + version before install; only new dependency this phase. |
</threat_model>
