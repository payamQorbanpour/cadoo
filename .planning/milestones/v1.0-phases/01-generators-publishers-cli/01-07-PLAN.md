<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flags / URL → ReleaseJob | Operator-supplied --repo/--from/--to/URL parsed before provider calls |
| `.cadoo.yaml` from ToRef tree → dispatcher config | Operator config from the tag tree drives which generators/publishers run |
| dispatcher → VCS write API (token) | The full run performs authenticated release-body + PR writes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing / Tampering | malformed --repo/URL flags | mitigate | Reuse `parseTargetURL` validation (Security V5); reject malformed tags/URLs before any provider call. |
| T-07-02 | Tampering | config loaded from main instead of tag tree | mitigate | Dispatcher loads `.cadoo.yaml` from `job.ToRef` only (copy loadCfg/isMissingFile); dogfood step 4 + TestIdempotentTwiceRun guard this (Pitfall 2). |
| T-07-03 | EoP | running a disabled generator | mitigate | `gen.Enabled(cfg, bump)` gate before Generate; TestDisabledNotGenerated asserts disabled/when:-excluded artifacts never run (D-08). |
| T-07-04 | Information disclosure | token leakage in CLI logs | mitigate | Reuse existing env contract; tokens never logged (mirror ci.go); no new secret names introduced. |
| T-07-05 | Tampering | duplicate PR / clobbered body on re-run | mitigate | Stateless marker reconstruction in publishers (Plan 06); dogfood twice-run + TestIdempotentTwiceRun prove single-PR + in-place body edit. |
| T-07-SC | Tampering | LLM prompt injection reaching production via dogfood | accept | release-notes narrative is bounded by the deterministic skeleton (Plan 05 T-05-01); changelog is golden-tested with LLM off; blast radius limited to prose wording. |
</threat_model>
